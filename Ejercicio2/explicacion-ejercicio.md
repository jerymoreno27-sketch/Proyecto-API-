# Explicación del Ejercicio 2

Este ejercicio permite guardar cómo estuvo el día del usuario utilizando el almacenamiento del navegador (Local Storage).

Primero, el usuario selecciona una opción del menú (por ejemplo: Excelente, Bueno, Regular o Malo). Luego puede guardar esa información para que permanezca almacenada incluso si cierra la página.

También es posible consultar el último estado guardado y eliminarlo cuando ya no se necesite.

- Se selecciona una opción de la lista.
- Al hacer clic en **Guardar**, el estado se almacena en el navegador.
- Al hacer clic en **Consultar**, se muestra el último estado guardado.
- Al hacer clic en **Limpiar**, se elimina la información almacenada.
