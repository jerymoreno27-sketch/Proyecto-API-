# Explicación del ejercicio

Este ejercicio muestra cómo guardar información en el navegador usando Web Storage.

La página tiene un cuadro para escribir un nombre. Al presionar "Guardar", ese nombre se guarda en el navegador, para que luego pueda recuperarse. También existe un botón para cargar el nombre guardado y otro para borrarlo.

Con esto se aprende de forma simple cómo usar localStorage para recordar datos sin necesidad de un servidor.
