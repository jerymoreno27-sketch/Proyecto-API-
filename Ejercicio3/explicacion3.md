# Explicación del ejercicio

Este ejercicio utiliza la API Web Storage mediante `localStorage`.

La página permite seleccionar un color de fondo con tres botones. Cuando el usuario elige un color, este se guarda en el navegador usando `localStorage`.

Al volver a abrir o actualizar la página, el color seleccionado se carga automáticamente.

Este ejemplo demuestra una forma sencilla de guardar las preferencias del usuario utilizando HTML5, CSS y JavaScript.
