#  Ejercicio 5 – Guardar nombre temporal con Session Storage

## Explicación

Este ejercicio guarda el nombre del usuario en **sessionStorage**, lo que significa que la información solo se mantiene mientras la pestaña del navegador está abierta.

Al cerrar la pestaña o el navegador, el dato se pierde automáticamente.

Esto es útil para almacenar información temporal durante una sesión de navegación, como datos de formularios o preferencias rápidas que no necesitan persistir después.
