# Explicaicón del ejercicio

Este ejercicio permite guardar el color favorito del usuario utilizando el almacenamiento del navegador
(Local Storage). 
El usuario selecciona un color con el cuadro de elección y puede guardarlo 
para que quede registrado incluso si cierra la página. 
Luego, al presionar el botón de mostrar, 
se recupera el color guardado y se aplica al texto en pantalla. 
También existe la opción de eliminar 
el dato almacenado. 
Con este ejemplo se aprende que Web Storage no solo guarda texto, sino también
otros valores como colores, lo que permite personalizar la experiencia del usuario de manera sencilla.
